# 더디에르 멤버 가이드

더디에르 멤버의 홈페이지 등록, 방송 준비, 자료 제출을 위한 독립형 안내 사이트입니다.

## 구성

- 홈페이지 등록용 12개 항목 및 방송용 소개 양식
- 20만 원대 / 40만 원대 개인 신호탄 안내
- 출근시간과 지각 기준
- 투네이션 설정 및 OBS 위젯 링크 전달 주의사항
- 관련 자료 링크 7종과 팀별 매니저 안내
- 전체/항목별 양식 복사, 브라우저 내 체크리스트 저장
- 모바일 대응 및 키보드 접근성

개인정보를 서버로 받거나 저장하지 않습니다. 체크리스트에는 항목별 완료 여부만 이 브라우저의 localStorage에 저장됩니다. 실제 자료는 담당 매니저에게 직접 전달합니다.

## 실행과 배포

빌드와 별도 패키지 설치가 필요 없는 HTML/CSS/JavaScript 사이트입니다. `index.html`을 열어 확인하거나 정적 HTTP 서버에서 이 폴더를 제공하세요. 클립보드 복사는 HTTPS/localhost 환경에서 작동하며, 권한이 없으면 직접 복사할 수 있는 창을 표시합니다.

GitHub Pages: 저장소 Settings → Pages → Deploy from a branch → `main`, `/(root)`를 선택합니다.

## 수정

- 안내 문구, 자료 링크: `index.html`
- 색상, 간격, 반응형 디자인: `styles.css`
- 복사 양식 및 체크리스트 동작: `app.js`

안내 항목을 수정할 때 `index.html`과 `app.js`의 복사 양식을 함께 갱신하세요. 자료 링크는 운영자 제공 주소이며 접근 권한은 각 서비스 설정을 따릅니다.
